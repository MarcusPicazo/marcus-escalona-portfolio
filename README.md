# Marcus Escalona - Product Engineer Portfolio

Welcome to my interactive portfolio! I am a Product Engineer specializing in the intersection of EdTech and interactive web systems. 

This repository houses the source code for my digital portfolio, an immersive web experience designed to showcase my projects in EdTech, 3D web environments, and real-time interactive systems.

## 🚀 Technical Highlight
This portfolio is built to reflect my development philosophy: reducing cognitive friction through immersive design while maintaining rigorous engineering standards.

### Core Technologies:
* **HTML5 & CSS3**: Custom layouts, CSS variables, native animations, and responsive grids.
* **Vanilla JavaScript (ES6+)**: Modular, dependency-free core logic.
* **GSAP & ScrollTrigger**: Complex timeline animations, cinematic transitions, and dynamic SVG morphing.
* **Lenis**: Hardware-accelerated smooth scrolling for premium UX.
* **Canvas API**: Procedural background particle systems.

## 🛠 Setup & Local Development
To run this project locally and avoid CORS issues when interacting with local assets:
1. Clone the repository.
2. Run `npm install`.
3. Run `npm start`.

# Marcus Escalona - Portafolio de Product Engineer

¡Bienvenido a mi portafolio interactivo! Soy un Product Engineer especializado en la intersección entre EdTech y sistemas web interactivos.

Este repositorio contiene el código fuente de mi portafolio digital, una experiencia web inmersiva diseñada para mostrar mis proyectos en EdTech, entornos web 3D y sistemas interactivos en tiempo real.

## 🚀 Aspectos Técnicos Destacados
Este portafolio está construido para reflejar mi filosofía de desarrollo: reducir la fricción cognitiva a través del diseño inmersivo manteniendo rigurosos estándares de ingeniería.

### Tecnologías Principales:
* **HTML5 & CSS3**: Layouts personalizados, variables CSS, animaciones nativas y grids responsivos.
* **Vanilla JavaScript (ES6+)**: Lógica principal modular.
* **GSAP & ScrollTrigger**: Animaciones de línea de tiempo complejas, transiciones cinemáticas y transformaciones dinámicas.
* **Lenis**: Desplazamiento suave (smooth scrolling) acelerado por hardware para una experiencia de usuario (UX) premium.
* **Canvas API**: Sistemas de partículas de fondo generados de manera procedimental.

## 🛠 Instalación y Desarrollo Local
Para ejecutar este proyecto localmente y evitar problemas de CORS:
1. Clona el repositorio.
2. Ejecuta `npm install`.
3. Ejecuta `npm start`.
